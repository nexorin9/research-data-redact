# 规模与性能基准：500 例材料的识别 → 一致代号 → 残留自检

> 数字由 `scripts/bench_scale.py` 在本机实跑得出（命令与参数见文末）；语料为 `scripts/gen_corpus.py` 固定种子合成的 **合成数据**，不含任何真实患者可识别信息。

## 一、结论

| 验收项 | 阈值 | 实测 | 差距 | 结论 |
|--------|------|------|------|------|
| 识别 + 残留自检总耗时（500 例） | ≤ 120 秒 | 1.04 秒 | +118.96 秒 | 通过 |
| 识别条目数 == 清单条目数 | 逐份相等 | 3500 == 3500 | — | 通过 |
| 每份材料都产出条目 | 无 0 条 | 0 份为 0 | — | 通过 |
| 单份体量落在 1–20 KB | 全部命中 | 0 份越界 | — | 通过 |
| 身份类残留（阻断级） | 0 处 | 0 处 | — | 通过 |

主指标「识别 + 残留自检」实测 **1.04 秒**，阈值 120 秒，**余量 118.96 秒**。全链路（含处置改写）1.10 秒。

## 四、耗时分位

**逐份材料**（单位：毫秒；`p95` 决定最慢的那份材料把一次批处理拖成什么样）

| 阶段 | P50 | P90 | P95 | P99 | 最大 | 合计 |
|------|-----|-----|-----|-----|------|------|
| 识别 | 1.08 | 1.62 | 1.72 | 1.81 | 1.85 | 533.6 毫秒 |
| 处置改写（冲突裁决 + 动作执行） | 0.12 | 0.14 | 0.15 | 0.17 | 5.95 | 63.8 毫秒 |
| 残留自检（二次扫描） | 1.01 | 1.55 | 1.63 | 1.72 | 7.56 | 506.6 毫秒 |

**整轮**

| 口径 | 耗时 | 说明 |
|------|------|------|
| 识别 + 残留自检（**验收主指标**） | 1.04 秒 | 阈值 120 秒 |
| 全链路（识别 + 处置改写 + 残留自检） | 1.10 秒 | 守护进程一批交付的实际等待时间 |
| 整轮墙钟（含语料装载与装配） | 1.71 秒 | 含装配注册表与主索引名单 |

## 五、峰值内存

| 口径 | 值 | 说明 |
|----|----|------|
| 进程峰值 RSS | 41.7 MiB | `getrusage(RUSAGE_SELF).ru_maxrss`，含解释器与基准脚本自身 |
| Python 堆峰值 | 1.1 MiB | `tracemalloc` 单独一趟量（带开销，不计入计时那一趟） |

守护进程是**常驻**的：内存不随批次数线性增长 —— 每批用完的注册表与主索引名单随批次对象释放，峰值取决于单批材料的体量，而不是累计处理量。

## 六、条目数守恒（无截断）

| 项 | 值 |
|----|----|
| 识别产出命中总数 | 3500 |
| 命中清单条目总数 | 3500 |
| 逐份守恒（识别数 == 清单数） | 全部相等 |
| 每份材料条目数最小 / 中位 / 最大 | 7 / 7 / 7 |

「识别数 == 清单数」是**无截断**的硬证据：命中清单是交差产物，少一条就意味着有一处命中没进清单 —— 人工复核会漏看那一处。两者相等说明识别层产出的每一处命中都落进了清单（含告警档与白名单放行项）。

## 七、复现方式

```bash
# 生成语料（固定种子，同种子两次生成逐字节一致）
python scripts/gen_corpus.py --limit 500 --seed 20260101 --out var/corpus

# 跑基准并写报告
python scripts/bench_scale.py --corpus var/corpus --out reports/performance.md

# 小规模快跑（调试用）
python scripts/bench_scale.py --limit 60
```

基准脚本**不静默通过**：主指标超出阈值时，报告写明实测值与差距，脚本以非 0 退出码收场。
